# Исследование C++

## Коротко
C++ — язык программирования, созданный Бьёрном Страуструпом в 1979-1983 годах как расширение C с объектно-ориентированными возможностями. Стал основным языком для системного программирования, игр и производительных приложений.

## Происхождение
**Кто:** Бьёрн Страуструп, датский ученый-программист  
**Где:** Bell Labs (AT&T), США  
**Когда:** 1979-1983 годы  
**Для какой задачи:** Добавление объектно-ориентированного программирования в C без потери производительности. Изначально назывался "C with Classes", переименован в C++ в 1983 году.

## Исходная проблема
Программистам нужен был язык, который:
- Сохраняет производительность и низкоуровневый контроль C
- Добавляет абстракции для управления сложностью больших проектов
- Поддерживает объектно-ориентированное программирование
- Позволяет повторно использовать код

## Пользователи и области применения
- **Системные программисты:** операционные системы, драйверы
- **Разработчики игр:** игровые движки, AAA-проекты
- **Финансовый сектор:** торговые системы, где важна скорость
- **Встраиваемые системы:** микроконтроллеры, IoT
- **Desktop-приложения:** Windows-программы, графические интерфейсы
- **Научные вычисления:** моделирование, симуляции

## Ключевые вехи
1. **1979** — Страуструп начинает работу над "C with Classes"
2. **1983** — язык переименован в C++
3. **1985** — первый коммерческий релиз C++ 1.0
4. **1990** — выход книги "The C++ Programming Language" (2-е издание)
5. **1998** — первый стандарт ISO C++98
6. **2003** — техническая поправка C++03

## Важные платформы, продукты и проекты
- **Microsoft Visual C++** — основная среда разработки для Windows
- **Borland C++** — популярный компилятор 1990-х
- **Windows API** — системный интерфейс Microsoft написан на C/C++
- **Unreal Engine** — игровой движок на C++ (с 1998)
- **Adobe Photoshop** — написан на C++
- **Mozilla Firefox** — браузер на C++
- **MySQL** — база данных на C++

## Почему объект был ценен в выбранную эпоху
В 1990-2000-е годы C++ стал языком выбора для:
- **Windows-разработки:** создание нативных приложений с прямым доступ к API
- **Игровой индустрии:** производительность критична для 3D-графики
- **Системного ПО:** операционные системы, драйверы устройств
- **Корпоративных приложений:** базы данных, финансовые системы

Объектно-ориентированный подход позволял управлять сложностью растущих проектов, а обратная совместимость с C давала доступ к существующему коду и библиотекам.

## Факты для рекламной концепции
- C++ использовался для создания Windows 95/98/XP
- Большинство AAA-игр 1990-х написано на C++
- "Learn C++" было одним из самых популярных запросов в книжных магазинах
- Зарплаты C++ программистов были среди самых высоких в индустрии
- Книги по C++ стоили дорого ($50-80) и были толстыми (800+ страниц)
