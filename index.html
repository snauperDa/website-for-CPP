Программа обучения — 6 месяцев, вечерние занятия

  1. Модуль 1. Основы C++ (4 недели)
    • Синтаксис, типы данных, операторы
    • Функции и указатели
    • Работа с памятью
  2. Модуль 2. Объектно-ориентированное программирование (6 недель)
    • Классы и объекты
    • Наследование и полиморфизм
    • Инкапсуляция
  3. Модуль 3. Windows API (8 недель)
    • Создание окон и диалогов
    • Обработка сообщений
    • Графический интерфейс (GDI)
  4. Модуль 4. Визуальная разработка (6 недель)
    • Microsoft Visual C++ 6.0
    • MFC (Microsoft Foundation Classes)
    • Создание полноценного приложения
  5. Модуль 5. Итоговый проект (4 недели)
    • Разработка собственного Windows-приложения
    • Презентация проекта
Microsoft Visual C++ 6.0 — среда, которую вы освоите в модуле 4.
