# Программа курса

## Назначение
Посетитель должен увидеть конкретный план обучения и понять, что курс дает практические навыки.

## Содержание
**Заголовок:** Программа обучения (6 месяцев, вечерние занятия)

**Модуль 1:** Основы C++ (4 недели)  
- Синтаксис, типы данных, операторы  
- Функции и указатели  
- Работа с памятью  

**Модуль 2:** Объектно-ориентированное программирование (6 недель)  
- Классы и объекты  
- Наследование и полиморфизм  
- Инкапсуляция  

**Модуль 3:** Windows API (8 недель)  
- Создание окон и диалогов  
- Обработка сообщений  
- Графический интерфейс (GDI)  

**Модуль 4:** Визуальная разработка (6 недель)  
- Microsoft Visual C++ 6.0  
- MFC (Microsoft Foundation Classes)  
- Создание полноценного приложения  

**Модуль 5:** Итоговый проект (4 недели)  
- Разработка собственного Windows-приложения  
- Презентация проекта  

**Цена:** 2,500,000 рублей (или $400 по курсу 1998 года)  
**Рассрочка:** 3 платежа без процентов

## Связь с объектом
Программа отражает реальный путь изучения C++ в конце 1990-х: от основ к Windows API и MFC.

## Связь с эпохой
Цены в рублях с указанием долларового эквивалента характерны для России 1998 года (после деноминации). Вечерние занятия для работающих людей.
