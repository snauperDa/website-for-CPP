# Главный экран: "Станьте архитектором будущего"

## Назначение
Посетитель должен почувствовать амбициозность предложения и понять, что C++ — это язык для серьезных разработчиков.

## Содержание
**Заголовок:** C++ ACADEMY  
**Подзаголовок:** Мастерство Windows-программирования  
**Основной текст:** Через 6 месяцев вы будете создавать собственные приложения для Windows 95/98 и получите работу с зарплатой от $500  
**Кнопка:** "Записаться на курс"  
**Декоративный элемент:** Изображение компьютера Pentium II с монитором, показывающим код на C++

## Связь с объектом
C++ был основным языком для Windows-разработки в 1990-2000-е годы. Зарплаты C++ программистов в Москве 1998-2000 годов составляли $500-1500.

## Связь с эпохой
Визуальный стиль Windows 95: объемные кнопки, серые панели, системный шрифт MS Sans Serif. Обещание высоких зарплат отражает реальный бум IT-рынка конца 1990-х.

## Визуальные ориентиры
- Объемные 3D-кнопки с градиентом
- Серый фон (#C0C0C0)
- Синий заголовок (#000080)
- Шрифт: Arial Bold для заголовков, MS Sans Serif для текста
- Плотная компоновка, минимум пустого пространства
