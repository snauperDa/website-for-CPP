# Требования к компьютеру

## Назначение
Посетитель должен понять технические требования и оценить доступность обучения.

## Содержание
**Заголовок:** Что нужно для обучения

**Минимальные требования:**  
- Процессор: Intel Pentium 133 MHz  
- Оперативная память: 32 MB RAM  
- Жесткий диск: 500 MB свободного места  
- Видеокарта: SVGA (256 цветов)  
- CD-ROM привод  
- Операционная система: Windows 95 или Windows 98  

**Рекомендуемые требования:**  
- Процессор: Intel Pentium II 300 MHz  
- Оперативная память: 64 MB RAM  
- Жесткий диск: 2 GB свободного места  
- Видеокарта: SVGA (High Color, 16-bit)  
- Звуковая карта (для мультимедийных примеров)  

**ПО входит в стоимость курса:**  
- Microsoft Visual C++ 6.0 (учебная лицензия)  
- Windows SDK  
- Учебные материалы на CD-ROM  

**Важно:** Если у вас нет компьютера, вы можете заниматься в нашем компьютерном классе в свободное время (12 рабочих мест с Pentium II 350 MHz)

## Связь с объектом
Требования отражают реальные системные требования для разработки на C++ в конце 1990-х.

## Связь с эпохой
Pentium II, 64 MB RAM, Windows 98 — типичная конфигурация 1998-1999 годов. Компьютерные классы были распространены в учебных центрах.

## Визуальные ориентиры
- Таблица требований в стиле Windows
- Иконки компонентов (процессор, память, диск)
- Выделение "минимальных" и "рекомендуемых" требований

## Ограничения
