# Проблема: "Почему другие языки не подходят"

## Назначение
Посетитель должен понять ограничения Basic, Pascal и других языков того времени, чтобы оценить преимущества C++.

## Содержание
**Заголовок:** Почему не Basic?  
**Текст:**  
- Basic слишком медленный для серьезных приложений  
- Pascal не поддерживает объектно-ориентированное программирование  
- Ассемблер требует слишком много времени на разработку  
- Java (1995) еще слишком нова и медленна  

**Вывод:** C++ — единственный язык, сочетающий производительность C и мощь ООП

## Связь с объектом
C++ создавался как расширение C с добавлением ООП. В 1990-е годы это было уникальное сочетание.

## Связь с эпохой
В конце 1990-х шли споры между сторонниками разных языков. C++ позиционировался как "профессиональный инструмент".
