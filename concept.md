# Концепция

## Название вымышленных курсов
**"C++ Academy: Мастерство Windows-программирования"**

## Идея одним предложением
Интенсивные вечерние курсы для начинающих программистов, которые хотят создавать настоящие Windows-приложения и игры на самом мощном языке конца 1990-х.

## Кто предлагает обучение
**"Компьютерная школа 'Профи-Софт'"** — частный учебный центр в Москве, основанный в 1996 году бывшими разработчиками из НИИ. Располагается в арендованном офисе рядом с метро, имеет компьютерный класс на 12 рабочих мест с Pentium II.

## Аудитория
- Студенты технических вузов (18-25 лет)
- Начинающие программисты, знающие Basic или Pascal
- Инженеры, переходящие из DOS в Windows
- Самоучки из компьютерных кружков
- Люди, желающие сменить профессию и получить высокооплачиваемую работу

## Главное обещание
**"Через 6 месяцев вы будете создавать собственные Windows-приложения и получите работу с зарплатой от $500"**

Обещание основано на реальном факте: зарплаты C++ разработчиков в Москве 1998-2000 годов составляли $500-1500, что было значительно выше среднего.

## Голос рекламы
**Уверенный, технический, амбициозный.**

Обращение к серьезным намерениям:
- "Для тех, кто хочет настоящего"
- "Не для слабаков"
- "Профессиональный уровень"
- "Инвестиция в будущее"

Используются технические термины как маркеры элитности: "объектно-ориентированное программирование", "визуальная разработка", "компонентный подход".

## Центральная шутка
**"C++ сложен, но зато вы сможете уволить своего босса и открыть свою фирму"**

Шутка играет на контрасте:
- Сложность языка (800-страничные книги, годы изучения)
- Амбиции выпускников (собственный бизнес, высокие зарплаты)
- Реальность конца 1990-х (бум IT-стартапов, "новые русские" программисты)

Дистанция для современного читателя: сегодня C++ не единственный путь к успеху, есть Python, JavaScript, но в 1990-х это был "царский путь" в программировании.

## Что посетитель должен понять об объекте
1. **C++ — это язык для серьезных задач:** операционные системы, игры, базы данных
2. **Объектно-ориентированный подход** позволяет создавать сложные программы
3. **Производительность** C++ недоступна другим языкам того времени
4. **Windows-разработка** требует знания C++ и Win32 API
5. **Карьерные перспективы:** высокие зарплаты, спрос на рынке

## Что агент не должен потерять при сборке
- Атмосферу конца 1990-х (визуальный стиль Windows 95/98)
- Техническую сложность как преимущество ("для серьезных")
- Обещание высоких зарплат и карьеры
- Конкретные факты о C++ (даты, продукты, компании)
- Юмор через контраст ожиданий и реальности
- Отсылки к культурным маркерам эпохи (журналы, игры, железо)
