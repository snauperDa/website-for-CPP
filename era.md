# Ключевая эпоха

## Временной диапазон
**1990-2000 годы** — десятилетие desktop-революции

## Почему выбран этот период
1. **Выход Windows 95 (1995)** — массовый переход на графические интерфейсы, C++ стал основным языком для Windows-разработки
2. **Расцвет игровой индустрии** — Doom (1993), Quake (1996), Unreal (1998) — все на C++
3. **Появление Visual C++** — Microsoft делает C++ доступным для массового разработчика
4. **Объектно-ориентированная революция** — ООП становится стандартом индустрии
5. **Книжный бум** — сотни книг по C++, курсы в компьютерных школах

## Технологическая среда
**Устройства:**
- IBM PC совместимые компьютеры (386, 486, Pentium)
- 8-16 MB RAM (начало периода), 64-128 MB (конец)
- Жесткие диски 500 MB - 10 GB
- VGA/SVGA мониторы (640x480, 800x600, 1024x768)
- CD-ROM приводы (стандарт распространения ПО)

**Операционные системы:**
- MS-DOS (начало периода)
- Windows 3.1 (1992)
- Windows 95 (1995) — революция
- Windows 98 (1998)
- Windows NT 4.0 (1996)

**Программы:**
- Microsoft Visual C++ 4.0-6.0
- Borland C++ 3.1-5.0
- Symantec C++
- Rational Rose (UML-моделирование)

**Сеть:**
- Dial-up модемы (14.4 - 56 kbps)
- Ранний интернет (WWW появляется в середине 90-х)
- Email, Usenet, IRC
- Локальные сети в офисах

**Носители:**
- 3.5" дискеты (1.44 MB)
- CD-ROM (650-700 MB)
- ZIP-диски (100 MB)

**Типичный экран:**
- Разрешение 800x600 или 1024x768
- 256 цветов (8-bit) или High Color (16-bit)
- CRT мониторы
- Системный шрифт: MS Sans Serif, Tahoma

## Визуальный язык
**Типографика:**
- Заголовки: Arial, Verdana, Tahoma (без засечек)
- Основной текст: MS Sans Serif, System
- Код: Courier New, Fixedsys
- Размеры: 8-12pt для текста, 14-18pt для заголовков

**Цвета:**
- Системные цвета Windows: серый (#C0C0C0), синий (#000080), белый
- Кнопки: объемные с градиентом (светлый сверху, темный снизу)
- Фон: серый или белый
- Акценты: синий, темно-синий

**Плотность:**
- Высокая плотность информации
- Много текста на экране
- Таблицы, списки, меню
- Минимум пустого пространства

**Рамки и кнопки:**
- Объемные 3D-рамки (bevel effect)
- Кнопки с четкими границами
- Вдавленные поля ввода
- Тени и блики для объема

**Изображения:**
- Пиксельная графика, иконки 16x16, 32x32
- Фотографии низкого разрешения
- Градиенты и объемные эффекты
- Clipart из коллекций

**Декоративные приемы:**
- Градиентные заголовки
- Объемные панели
- Разделительные линии
- Иконки рядом с текстом
- "Embossed" и "engraved" эффекты

## Рекламный язык
**Обещания:**
- "Мощность" и "производительность"
- "Профессиональный уровень"
- "Создавайте настоящие приложения"
- "Полный контроль над системой"
- "Будущее программирования"

**Интонации:**
- Техническая уверенность
- Обращение к амбициям ("станьте профессионалом")
- Акцент на сложности и серьезности
- Обещание высоких зарплат
- Сравнение с "простыми" языками (Basic, Pascal)

**Характерные формулировки:**
- "Для серьезных разработчиков"
- "Промышленный стандарт"
- "Максимальная производительность"
- "Объектно-ориентированный подход"
- "Визуальная разработка"

## Культурный фон
**Журналы:**
- PC Magazine, PC Week
- Dr. Dobb's Journal
- C/C++ Users Journal
- "Программист" (российский)

**Игры:**
- Doom, Quake, Unreal
- StarCraft, Diablo
- Half-Life (1998)

**Кино:**
- "Хакеры" (1995)
- "Сеть" (1995)
- "Матрица" (1999)

**Музыка:**
- Техно, электронная музыка
- Soundtrack из игр (MIDI, CD-audio)

**Офисная культура:**
- Открытые пространства с рядами компьютеров

- Кофе и пицца во время дедлайнов
- "Крутые программисты" в черных футболках

**Интернет-культура:**
- Ранние веб-сайты с таблицами
- Гостевые книги
- Чаты и форумы
- "Under construction" gif-ки

## Границы стилизации
**Что разрушит образ:**
- Скругленные углы (border-radius)
- Градиентные фоны в современном стиле
- Минимализм и много пустого пространства
- Мобильная адаптация
- Современные шрифты (Roboto, Open Sans)
- Flat design
- Анимации и transitions
- Тени в современном стиле (box-shadow)
- Flexbox и Grid layouts (слишком современные)
- Emoji и современные иконки
