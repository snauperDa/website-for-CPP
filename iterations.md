# Итерации

## 1. Эпоха и визуальная точность

**Проблема:** 
После первой сборки агент создал страницу с современным минималистичным дизайном: скругленные углы у кнопок и карточек (border-radius), много белого пустого пространства, шрифт sans-serif без засечек в стиле 2020-х, градиентные фоны в пастельных тонах. Страница выглядела как типовой лендинг 2024 года, а не как реклама конца 1990-х. Отсутствовали характерные для Windows 95/98 объемные 3D-кнопки с эффектом bevel, системный серый цвет (#C0C0C0), плотная компоновка информации. Также агент использовал современные тени (box-shadow) вместо характерных для эпохи вдавленных и выпуклых рамок.

**Инструкция агенту:** 
"Проанализируй era.md и sources.md. Убери все скругленные углы (border-radius: 0), замени современный минимализм на плотную компоновку в стиле Windows 95. Используй системные цвета: фон #C0C0C0, заголовки #000080, текст черный. Замени современные тени на объемные 3D-рамки: светлая граница сверху и слева (#FFFFFF), темная снизу и справа (#808080). Замени шрифты на Arial для заголовков и MS Sans Serif для текста. Добавь характерные для эпохи элементы: таблицы с видимыми границами, кнопки с четким 3D-эффектом, иконки рядом с заголовками. Убери пустое пространство между секциями — информация должна быть плотной, как в компьютерных журналах 1998 года."

**Что изменилось:** 
- Все border-radius заменены на 0
- Фон страницы стал серым (#C0C0C0) вместо белого
- Кнопки получили объемный 3D-эффект с границами #FFFFFF/#808080
- Шрифты заменены на Arial и MS Sans Serif
- Добавлены таблицы с видимыми границами для программы курса и требований к компьютеру
- Плотность информации увеличена: уменьшены отступы между элементами
- Заголовки стали синими (#000080) как в типичных Windows-приложениях
- Добавлены декоративные элементы: горизонтальные линии-разделители, иконки-маркеры

**Почему это улучшило соответствие эпохе:** 
Страница теперь визуально соответствует интерфейсу Windows 95/98 и рекламным материалам конца 1990-х. Объемные кнопки, серый фон и плотная компоновка — характерные признаки эпохи, которые сразу создают нужную атмосферу. Современный читатель сразу видит дистанцию между тогдашним и нынешним дизайном, что усиливает исторический эффект.

## 2. Смысл и история объекта

**Проблема:** 
После первой итерации страница выглядела визуально правильно, но текст был слишком общим и шаблонным. Фразы вроде "C++ — мощный язык программирования" и "создавайте профессиональные приложения" не передавали конкретную историческую ценность C++ в 1990-2000-е годы. Недоставало привязки предложения к реальным инструментам эпохи (Visual C++ 6.0, MFC, Windows API) и к реалиям московского IT-рынка 1998-1999 годов. История выпускника звучала как типовой отзыв без конкретных цифр. При этом возникал соблазн придумать яркие "факты" (сравнения скорости, среднюю зарплату по Москве) — что запрещено подходом проекта.

**Инструкция агенту:** 
"Опирайся только на research.md, concept.md и blocks/*.md. Не выдумывай статистику, рейтинги и даты — используй цифры только из материалов ($500-1500, 800 000 рублей, $400 по курсу 1998 года). Упомяни реальные инструменты эпохи: Visual C++ 6.0, MFC, Windows API. Программу курса построй из пяти модулей по реальному пути изучения C++ конца 1990-х: основы → ООП → Windows API → визуальная разработка → итоговый проект. В истории выпускника укажи переход от системного администрирования к разработке и зарплату в долларах. Каждый факт проверь по research.md; спорные утверждения не добавляй."

**Что изменилось:** 
- Программа курса построена из пяти модулей по реальному пути изучения C++: основы, ООП, Windows API, визуальная разработка (Visual C++ 6.0 + MFC), итоговый проект
- В герое-блоке и программе упомянуты конкретные инструменты эпохи: Windows API, Microsoft Visual C++ 6.0, MFC
- История выпускника получила конкретику Москвы 1999 года: переход от сисадмина (800 000 рублей) к разработке за $800, рост до $1500, три оффера
- В разделе "Почему не Basic" оставлены только проверяемые обоснования из блока 02 (скорость, отсутствие ООП, новизна Java) без выдуманных цифр сравнения
- Цена курса привязана к эпохе: 2 500 000 рублей (~$400 по курсу 1998 года) с рассрочкой
- Требования к компьютеру взяты из блока 06 (Pentium 133/Pentium II 300, 32/64 МБ, Windows 95/98)
- Выдуманные утверждения (скорость Basic "в 10-100 раз", средняя зарплата по Москве) в страницу НЕ добавлены

**Почему это сделало страницу содержательнее:** 
Страница держится не на абстрактных эпитетах ("мощный язык"), а на проверяемых фактах эпохи: конкретных инструментах, цифрах зарплат и ценах в рублях с долларовым эквивалентом. Каждый блок теперь связан с research.md и concept.md, предложение курсов выглядит убедительным для человека 1999 года, а современный читатель видит, почему именно C++ был "царским путем" в программировании конца 1990-х, без приписанных истории мифов.
